# 평가 · 실험 기록

질문 126개(dev 95 · test 31)로 검색 · 답변을 재고, 설정은 숫자로 정했습니다. 실험 원자료는 [`eval/results/`](../eval/results), 실험 설명은 [`eval/EXPERIMENTS.md`](../eval/EXPERIMENTS.md).

## 평가 방법

| 항목 | 내용 |
|---|---|
| 질문 | 126개(dev 95 · test 31) = 금융 90(전자금융 · 개인정보 · 신용정보) + 생활 36(민사 · 소비자 · 사기). 유형(상황 · 정의 · 숫자 · 법+시행령 교차)별로 나눔. 정답 = 답이 실제로 있는 조문(1~3개) |
| 지표 | hit@k(정답 조문이 상위 k 안에 있는 질문 비율), recall@k(정답 조문 중 상위 k 안에 든 비율), MRR(첫 정답 순위 역수) — 청킹이 달라도 비교되게 **조 단위**로 채점 |
| 절차 | 설정 결정은 dev 로, test 는 확정 뒤 확인용. test 에서 본 설정은 아래 표에 전부 실었습니다 |
| 답변 평가 | 인용 조문 ∩ 정답 조문, 별도 Claude 판정(충실성 = 받은 근거에 있는 말만 했는가 / 정확성 = 정답 조문과 결론 일치), 범위 밖 질문 10개 거절률 |

재현: `node scripts/fetch.mjs` → `node eval/run.mjs --split dev --models bge-m3 --modes bm25,dense,hybrid [--rewrite --w 1,1]` → `node eval/answer_eval.mjs --split test`

### 정정 — 틀리게 잰 것 · 틀리게 답한 것

- **bge-m3 를 처음엔 mean 풀링으로 돌려** hit@5 0.42 로 "나쁜 모델"처럼 나왔습니다. bge-m3 는 CLS 풀링이 표준이라 고쳐 다시 재자 가장 좋은 모델이 됐습니다. 임베딩 캐시 키에 풀링이 없어 옛 캐시가 재사용될 위험이 있어 캐시도 지우고 다시 만들었습니다.
- **판정관 설계 결함**: 처음 답변 평가는 충실성을 "정답 조문에 있는가"로 재서, 모델이 받은 시행령 · 타법 조문을 정당하게 인용해도 깎았습니다(충실성 0.48). "모델이 받은 근거에 있는가"로 고쳐 다시 쟀습니다. **이 수정은 test 결과를 본 뒤에 한 것**입니다.
- **haiku 가 더 빠를 거라는 가정**이 이 환경(`claude -p` 호출)에서는 틀렸습니다 — 답변 평균 haiku 9.9초 vs sonnet 3.8초, 재작성 7.6초 vs 2.2초(각 3문항 1회 측정). 정확성도 sonnet 이 약간 높았습니다.
- **"근거에 충실"해도 법적으로 틀린 답**: 중고 노트북 환불 질문에서 모델이 "하자 권리는 안 날부터 **1년** 내 행사"라고 답했습니다. 제580조는 제575조 **제1항만** 준용하는데, 참조 조문 전체를 근거에 붙이자 모델이 준용되지 않는 제3항(1년)을 끌어다 썼습니다(실제 하자담보 기간은 제582조의 6개월). 근거 안에 있는 말이라 충실성 판정으로는 안 잡혔고, **답변을 직접 읽어서** 발견했습니다. 프롬프트 규칙만으로는 안 막혀서 **참조가 항을 지정하면 그 항만 붙이도록** 구조를 바꿨고, 고친 뒤 같은 질문은 "해제 가능 기간은 근거에서 확인할 수 없다"고 답합니다.

## 한계 — 숫자를 읽을 때 주의

- **질문 · 정답 세트는 Claude(Sonnet)가 조문을 읽고 초안을 썼고**, 정답 키 존재 여부만 기계 검증했습니다. 사람이 전수 검수하지 않았습니다. 질문 작성 모델과 서비스 모델이 같은 계열입니다.
- test 31문항(생활 6)은 표본이 작아 ±0.1 이상의 오차를 봐야 합니다. 설정 결정은 dev(95)로 했지만 test 에서 여러 설정을 본 뒤 확정했으므로 완전히 깨끗한 확인용은 아닙니다.
- **알려진 실패**: ① 개인 판매자에게 전자상거래법이 적용되는지(제2조 · 제20조의4)를 못 찾아 "당근 환불" 예시가 "근거 없음"으로 답합니다. ② 같은 상황에서 전자상거래법이 민법 · 형법을 밀어내는 경우가 있습니다(가품 취소 → 민법 제110조, 가짜 쇼핑몰 미수 → 형법 제352조를 놓침). ③ 정의 · 권리행사 기간처럼 질문과 어휘가 멀리 있는 조문(제2조, 제582조 등).
- 기존 금융 질문의 정답은 코퍼스가 커진 뒤 다른 법의 조문도 정당한 답일 수 있어(예: 퇴사자 명단 유출 → 형법 업무상 배임) 일부 지표가 낮게 나올 수 있습니다.
- RRF 가중은 임베딩 모델 · 코퍼스가 바뀔 때마다 다시 재야 합니다(e5-small 3:1 → bge-m3 1:3 → 코퍼스 확대 후 차이 없음).
- 법령은 2026-10 시점 현행 기준 스냅샷입니다. 매우 긴 조는 찾은 항만 답변 근거로 넘깁니다(3,500자 상한).
- 질의 재작성이 Claude 호출을 한 번 더 써서 지연이 늘어납니다(재작성 ~2초 + 답변 ~4초).
